# Slime Escape

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/alxdos/slime-escape)

A game by Wertakull.

Escape the slime nightmare: survive the waves while the darkness closes in, use the short breaks when it pulls back, and defeat the one who trapped you in this world.

![Slime Escape splash](public/images/slime-escape.jpg)

## Play

- Main game: https://slimeescape.com
- Portal entry: https://slimeescape.com/portal

## About

Slime Escape is a fast survival action game about waking up inside a strange arena, fighting through escalating slime waves, and finding a way out before the darkness closes in.

## Development

Requires Node.js 22+ and npm 11+.

```bash
npm install
npm run dev      # Vite dev server at http://127.0.0.1:5173
npm run build    # production build into dist/
npm run preview  # local preview server for the built bundle
npm run typecheck
```
