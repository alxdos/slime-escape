# Drops

- Status: planned
- Created: 2026-04-19
- Updated: 2026-04-19

## Player-facing

- Sees: с убитых врагов с заметной вероятностью выпадает дроп; объект лежит на арене и подсвечен.
- Can do: подойти и подобрать дроп, увидеть применённый эффект (например, восстановление HP).

## Technical

- Базовая `drop table` в `content library` (1–2 типа дропа).
- `DropSystem`: спавн дропа по death hook, время жизни, удаление по таймауту.
- Подбор по spatial overlap игрока с дропом через `SpatialIndex`.
- Применение эффекта дропа на игрока (минимум один тип, например healing).
- Расширение снапшотов: активные drop-объекты для рендера.

## Out of scope

- Инвентарь, экипировка во время боя, выбор предметов.
- Сложные таблицы дропа с тирами и модификаторами.
- Магнит, авто-подбор на расстоянии.

## Acceptance

- При смерти врага дроп спавнится согласно таблице вероятностей.
- Дроп виден на арене и исчезает по таймауту, если не подобран.
- Контакт игрока с дропом подбирает его и применяет эффект ровно один раз.
