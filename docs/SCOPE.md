# Объём работ (Scope): MVP и дальше

## Обязательно для первого играбельного билда (MVP)

| Фича |
|------|
| Одна арена, top-down камера и базовое управление **человеком** |
| Одна основная атака оружием и модель урона по врагам-слаймам |
| Полоска здоровья игрока и поражение при её обнулении |
| **Тёмная зона**: линейно сужается во время волны, **почти полностью отступает после каждой волны**, отключается в бою с боссом |
| Минимум **2 типа обычных врагов** + различимое поведение |
| Система волн: **ровно 3 волны** перед боссом + автоматический переход к следующей волне по таймеру |
| Дроп с врагов и награда после отступления тёмной зоны (например восстановление здоровья или временное усиление) |
| Короткая **межволновая передышка** с автоматическим стартом следующей волны по таймеру |
| **Босс** как минимум с **двумя фазами** (третья — желательно, см. ниже), бой **без** тёмной зоны |
| Экран победы / поражения и быстрый перезапуск забега |
| Только интерфейс и минимум текста в MVP |
| Забег без сохранений: один сеанс от старта до победы или поражения |
| Основной клиент: **веб на десктопе** |
| Пробное **сенсорное управление** для мобильного веба, если оно не усложняет MVP |

## Желательно сразу после MVP (ещё до «полировки»)

| Фича |
|------|
| Третья фаза босса с одной уникальной механикой |
| Временные баффы с дропа |
| Настройки чувствительности и базовые опции доступности (масштаб интерфейса, более заметные зоны попадания — по возможности) |
| Простейшее главное меню и пауза |
| Газовые области как отдельный тип опасности |

## После MVP / отложить

| Фича |
|------|
| Мета-прогресс между ранами (разблокировки, постоянные апгрейды) |
| Несколько арен и биомов |
| Множество статус-эффектов и сложный крафт |
| Сетевая таблица лидеров |
| Нарратив кампании с несколькими боссами |
| Дополнительные режимы (бесконечные волны, ежедневные испытания) |

## Явно «вырезать» на данном этапе

- Полноценная сюжетная кампания на часы без арены-коробки.
- Открытый мир или процедурная генерация уровней сверх одной карты.
